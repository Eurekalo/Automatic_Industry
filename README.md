**This is an ONI mod replacement from reverse-engineered code, aimed at achieving automated operations.**  
**Designed to reduce tedious manual building operations by Duplicants, improve gameplay experience, and assist in debugging other projects.**

***This mod is a migration effort based on the original mod below. Please give thanks to the original author (一见倾心):***  
[https://steamcommunity.com/sharedfiles/filedetails/?id=2992024030](https://steamcommunity.com/sharedfiles/filedetails/?id=2992024030)

## Note

**This mod has not been fully and thoroughly tested yet. If you encounter game crashes, errors, or unexpected behavior during gameplay, please enable detailed logging in this mod's panel first. Use a third-party file hosting service to attach the relevant error logs in the comment section along with a detailed description of the issue, which will help locate the problem quickly.**

This mod cannot guarantee compatibility when enabled alongside other mods with similar functionality, nor can it prevent potential crashes or damage to game saves and content caused by abnormalities.

If you have requests for automating additional stations or suggestions for improving existing automations, please feel free to submit your suggestions or ideas.

This mod should support DLCs released before August 2026 (including the Aquatic Planet Pack DLC).

## Content

This mod supports English (default), Simplified Chinese, Traditional Chinese, Korean, and Japanese.

This mod supports writing detailed logs to `player.log`.

This mod should support automated work for the following buildings, including individual enabling or disabling options:
